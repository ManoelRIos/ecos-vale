ECOS DA MEIA-NOITE - UNITY

1. Instale Unity 6000.0.85f1 pelo Unity Hub.
2. Extraia TODO o ZIP em uma pasta nova, como C:\Dev\EcosDaMeiaNoite.
   Preserve sua copia anterior e quaisquer alteracoes proprias.
3. Feche o Editor que estiver aberto em outra copia.
4. Execute ABRIR_ECOS_DA_MEIA_NOITE.cmd na pasta nova.
5. Aguarde a resolucao dos pacotes e a compilacao. Pressione Play e inicie
   uma incursao no menu. Se abriu pelo Hub, use Ecos > Abrir roguelike
   enquanto o Play estiver parado.

A pasta aberta deve conter Assets, Packages e ProjectSettings.
Cena do jogo: Assets/_Game/Scenes/Haunt.unity.
Log do atalho: Logs/MeiaNoite-Editor.log.

Use uma pasta nova ao atualizar por ZIP. Sobrepor arquivos nao remove os
arquivos que deixaram de fazer parte do projeto. Um clone Git atualizado
aplica as remocoes rastreadas. O projeto agora contem somente o roguelike.

Controles: WASD mover, mouse mirar, esquerdo atirar, Espaco/direito esquivar,
E para portal/sair da loja, M mapa, Esc pausa. Caminhe ate portas abertas
para mudar de sala. Compre pelos botoes do mercado apos vencer o chefe.
Morrer encerra a incursao; nao ha save entre sessoes.

O Editor nao esta instalado no ambiente desta revisao. Os checks do nucleo
C# e estaticos nao substituem importacao/Play Mode. O atalho nao foi
executado no Windows aqui. Nao ha executavel Windows validado.
Veja README.md para instrucoes, testes e limites atuais.
