ECOS DO VALE - ABERTURA EM CAMINHO CURTO NO WINDOWS

1. Feche o Unity Editor.
2. Extraia este ZIP em C:\Dev. A pasta do projeto deve ficar:
   C:\Dev\EcosDoVale
   Nela devem existir Assets, Packages, ProjectSettings e este arquivo.
3. Execute ABRIR_ECOS_DO_VALE.cmd dentro dessa pasta.
   Ele recusa caminhos acima de 60 caracteres e abre a propria pasta.
   O Editor esperado e Unity 6000.0.85f1, instalado pelo Unity Hub.
4. Aguarde o Package Manager e a compilacao terminarem.
5. Abra Assets/_Game/Scenes/Valley.unity e pressione Play.

Se o Editor estiver instalado fora do caminho padrao, use no Hub:
Add project from disk -> C:\Dev\EcosDoVale, com Editor 6000.0.85f1.

SE QUISER USAR SUA COPIA ATUAL EM VEZ DE EXTRAIR NOVAMENTE:
Feche o Unity, mova a pasta REAL do projeto (a que contem Assets, Packages
 e ProjectSettings) para C:\Dev\EcosDoVale e renomeie a pasta Library
para Library_backup antes de abrir. Isso preserva o cache incompleto e
permite que o Unity o regenere. Preserve quaisquer alteracoes suas.

O ultimo log ja nao tinha erros CS1069 e Physics 2D foi carregado.
Os erros novos ocorriam em arquivos com caminhos de 260 a 288 caracteres,
forte indicio do limite de caminhos do Windows. O novo ZIP usa o nome
curto EcosDoVale para evitar pastas aninhadas com hashes longos.

O log da abertura via atalho fica em Logs/Ecos-Editor.log.
O atalho nao altera seus arquivos, nao apaga caches e nao muda o Registro
do Windows. Ele recebeu revisao estatica, mas nao foi executado no Windows.
A compilacao completa e o Play Mode ainda precisam ser confirmados no Editor.
